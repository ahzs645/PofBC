# Municipal and school district logo vector search

November 25, 2026

[Coverage inventory](coverage.csv) lists the designs and the subjects without artwork in both gallery sections. It records the default, the vector files held, any applicable brand guide, and the remaining source leads. This pass inventoried 164 local-government subjects and 91 school district subjects, including 31 former districts. It followed their publisher sites, brand materials, previously cited publications, and selected public reports. The automated visual screen checked 2,146 PDF pages in 279 subject and publication pairs. This included repeat checks of sources where a PDF was relevant to several subjects. Colour, artwork, typography and layout were checked visually before accepting vectors.

## School districts

The 2023 Stikine compensation filing supplied the earlier full-colour crest with “DISTRICT #87 STIKINE” in the arched lettering. It has a separate design record. The current crest, which omits the number sign, still uses the website image. The district catalogue continues to have 29 verified vector defaults across 60 current districts. [Stikine Executive Compensation Disclosure, p. 1](https://www.publicsectorcompensation.gov.bc.ca/executive-compensation-disclosures/2022-2023/113016/School-District-87-Stikine-ECD-2023pdf#page=1)

The current title-case Nanaimo Ladysmith signature remains open. Its 2024–2028 strategic plan and the 2026–2027 Learning Alternatives report both contain a source vector with the earlier uppercase wordmark. Gold Trail’s plan also supplied a vector in a different lettering treatment. The catalogue already holds those earlier designs. ## Extraction records

Each accepted file records the publisher, source page or SVG locator, extraction method, and SHA-256 checksum. PDF crops retain native paths, strokes and outlined lettering. Alternate versions preserve the source ink, with theme display copies built separately. The prior raster audit and district review remain the record of earlier checks.
