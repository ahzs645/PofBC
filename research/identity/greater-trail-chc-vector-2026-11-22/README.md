# Greater Trail Community Health Council, vector reconstruction, 22 November 2026

This is a supplied vector reconstruction of the council's people-and-oval logo (revision 2 of the
package). The original artwork has not been found. `scripts/build-collected-marks.mjs` reads
`proposed-assets.json` (VECTOR_SEARCHES). The package's own README is
[`package-README.md`](package-README.md).

## In the gallery

The reconstruction leads the council's card. The archived 2001 website GIF
(`historical-greater-trail-2001-web`) becomes its "Published image" version, so links to that mark
still open on the GIF. The vector PDF and the symbol alone (SVG) are offered as extra downloads.

## What it follows

The target is a supplied screenshot (`source/Reference-Supplied-Screenshot.png`, 1166 × 488) of
unknown publication and date. It is not the 2001 GIF. The screenshot has heavier oval bands and
differently lettered small capitals, so the GIF corroborates the design family, not the exact
master (`source/source-evidence.md`).

The caption's outlines are derived from Albertus, and GREATER / TRAIL uses custom serif capitals.
Neither is a confirmed historical typeface. No font file is included, and all lettering is outlined.
Overlap figures are in `source/overlap-audit.md` and `comparison-metrics.json`.
