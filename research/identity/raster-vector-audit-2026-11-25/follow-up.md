# Gallery vector imports and follow-up search

November 25, 2026

## Gallery imports

The [gallery](http://localhost:5173/dev/data?view=gallery) now holds all 14 source vectors identified in the [initial audit](README.md). Nine matching vectors became default artwork. The matching 2019 Geoscience BC vector joins the 2022 source vector already set as that design’s default. Quickpass, Castlegar, Vernon and Richmond School District have selectable alternate colourways. Their main artwork uses the gallery’s existing colourways.

The earlier raster specimens remain selectable. The Shared Services BC reconstruction also remains available. The source registration records the publisher, PDF page, extraction bounds and file checksums. The Shared Services BC brochure’s sun uses vector shading within the logo region. [Source details](../../../src/gallery/acquiredVectorData.js) · [Shared Services BC brochure, p. 16](https://www2.gov.bc.ca/assets/gov/british-columbians-our-governments/services-policies-for-government/real-estate-space/rpd_brochure.pdf#page=16)
