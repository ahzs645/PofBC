## Extraction

`extract.py` verifies both source PDFs against their recorded checksums. It isolates each tagged brochure figure or the final drawing group from the Naramata cover and retains the PDF’s clipping geometry. Poppler/Cairo converts the native vectors to browser SVGs and converts the source colours to RGB. The extractor checks that each SVG has paths and has zero embedded images. PyMuPDF renders the three bitmap-containing figures. The gallery’s display pipeline generates the theme-specific SVGs separately from the source artwork.

```sh
python3 research/identity/bear-smart-communities-2026-11-25/extract.py \
  /path/to/bearsmart_brchr.pdf public --naramata-strategy /path/to/naramata-strategy.pdf
```
