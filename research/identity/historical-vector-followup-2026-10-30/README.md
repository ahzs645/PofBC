## Gallery integration and verification

`scripts/build-collected-marks.mjs` reads this additional register, verifies files against their checksums, rejects unknown body IDs and duplicate asset IDs/file paths, and keeps detailed extraction evidence outside the gallery bundle. Adding an actual specimen changes a formerly unresolved body to `asset-collected`; it does not imply that a vector was found. The Capital source preview has a separately verified checksum.

Validation commands:

```sh
npm run build:collected-marks
node --test src/gallery/collectedCollections.test.js src/gallery/collections.test.js src/gallery/collecting.test.js src/gallery/wanted.test.js
npm run build
git diff --check
```

For pass 5, the gallery-index build writes **183 body records, 158 body assets and 15 program specimens**. All four listed test files, nine new asset/hash/dimension checks and `git diff --check` pass. An independent review reproduced the Sunshine Coast slice assembly, South Cariboo orientation correction, Vancouver/Richmond DIB decoding and both Crown pixel extractions. All 19 prior follow-up assets, including the eight SVGs, are unchanged.

The earlier PR #15 integration also checked the government-panel logo cards: all eight vectors appeared for the seven upgraded bodies, Capital used its source-page preview, and raster-only Simon Fraser and North Shore were excluded. The full `npm run build` was attempted during that integration and stopped at the existing Helvetica prerequisite: this Linux workspace has no licensed `/System/Library/Fonts/Helvetica.ttc`. The fifth pass does not claim a successful full production build. No substitute font or build bypass was introduced. The repository’s existing Pages workflow uses macOS and checks for that font before building.

All document dates and archive captures are specimen sightings. They do not establish first use, adoption dates or complete usage periods. The fifth pass uses October 31, 2026 in America/Creston; earlier passes retain their October 30 observation dates and older supporting artifacts may retain their original UTC timestamps. The directory name is the follow-up's start date. Full publications are linked and checksummed rather than copied into this repository.
