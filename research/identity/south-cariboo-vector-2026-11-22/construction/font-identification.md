# Lettering identification and reconstruction

## Result

**ITC Souvenir Demi is the strongest tested family/weight match.** The reconstruction uses the native vector letterforms shown in Monotype's official ITC Souvenir specimen, then adjusts the horizontal and vertical proportions of each line and the positions of individual letters to match the supplied 315 × 141 image. The lettering has not been generated by tracing the pixels in the uploaded logo.

This is a **visual identification**, not documentary confirmation of the council's original font file or supplier. The exact historical cut may differ from the modern `SouvenirStd-Demi` specimen. Its small rounded terminals and spacing are among the remaining points to compare if a larger original is found.

## Primary typeface evidence

Monotype, *Type Trends / Free Fonts / Type Specimen*, PDF page 8:

https://hello.monotype.com/rs/800-DWE-978/images/MT_TypeTrends_FreeFonts_TypeSpecimen.pdf

The page identifies ITC Souvenir, includes a complete Demi alphabet, and shows the family's other weights. The PDF's creation metadata is 25 March 2021. That date belongs to the specimen document and does **not** date the South Cariboo logo or its original typography.

The identifying features are the rising crossbar and tilted counter of the lowercase **e**, the sloping head serifs on **h/l**, the rounded **C**, the shape of the **y** tail, and the substantial lowercase proportions. Those details are more useful than simply classifying the lettering as a bold serif.

## Candidates tested

The following are initial whole-line fits before the final individual spacing adjustment. Each candidate received independent position and horizontal/vertical scale fitting. The comparison used the clear-background part of the lettering (`x ≥ 140`), avoiding the pale tree behind the initials. Values are mean binary intersection-over-union across the four lines; they are pixel agreement measurements, not probabilities of correct identification.

| Candidate | Initial mean overlap |
| --- | ---: |
| ITC Souvenir Demi | 85.6% |
| DejaVu Serif Bold | 78.1% |
| Liberation Serif Bold | 78.2% |
| Georgia Bold | 76.3% |
| Nimbus Roman Bold | 76.2% |
| Times New Roman Bold | 75.6% |
| Noto Serif Bold | 76.5% |
| URW Bookman Demi | 76.2% |
| C059 Bold | 76.3% |
| P052 Bold | 72.4% |
| Microsoft Goudy Old Style Bold | 62.8% |
| GT Goudy Extra Bold | 66.1% |

Times and Georgia were useful initial hypotheses, but their lowercase **e** does not reproduce the source's distinctive rising crossbar. Goudy was investigated because it shares some oldstyle details; both actual Bold and Extra Bold specimen letterforms fit materially worse. A synthetic thickening of Goudy Bold did not resolve the mismatch. DejaVu has broadly compatible weight and proportions but is not the chosen reconstruction because it misses the characteristic letterforms.

The GT Goudy Extra Bold comparison came from Gemini's official formed-plastic lettering specimen, PDF page 2:

https://geminimade.com/wp-content/uploads/FormedPlastic_DepthsStrokes.pdf

## Final construction

The final SVG has four named groups and 34 individually editable glyph paths. Every glyph is built from the font's vector contours. Letter positions are explicit. The reconstruction contains neither a raster image nor an embedded font file.

| Line | Horizontal em size, in source pixels | Vertical em size, in source pixels | Baseline |
| --- | ---: | ---: | ---: |
| South Cariboo | 26.337 | 29.137 | 44.698 |
| Community | 33.266 | 34.779 | 75.747 |
| Health | 32.875 | 35.110 | 107.987 |
| Council | 32.794 | 35.334 | 140.330 |

The horizontal compression is fitted to the supplied raster; it should not be interpreted as proof that the original designer used those exact settings. Small variations between the three lower lines reflect a fit to a low-resolution, resampled image. Repeated characters use the same native glyph design.

## Rendered-vector validation

The actual outlined SVG was rendered at four times the source resolution and reduced to 315 × 141 for a second comparison. This check uses clean-background crops beginning at `x = 134`, with line-specific bounds to avoid the previous line's descender. The source foreground was estimated from its dark green colour against white.

| Line | Rendered vector overlap |
| --- | ---: |
| South Cariboo | 87.9% |
| Community | 91.6% |
| Health | 87.9% |
| Council | 88.3% |

The mean is **88.9%** in these particular crops. The complete-logo report may use a different, stricter fixed-grid colour classification and therefore has its own directly comparable numbers. Neither measurement certifies the font name or the reconstruction's historical authenticity.

The initial letters partly overlie the pale tree and were registered visually rather than treating pale background pixels as dark lettering coverage. The original source's pixel antialiasing and compression also place a practical limit on an exact comparison.

## Files

- `lettering-outlined.svg`: canonical shape-only vector lettering, viewBox `0 0 315 141`.
- `lettering-editable.svg`: live-text alternative with explicit letter positions; requires a compatible installed ITC Souvenir Demi font. Font binaries are not included.
- `lettering-fit.json`: final parameters, original source metadata, comparison scopes and numerical checks.
- `lettering-preview.png`: rendered outlined lettering for inspection.

The outlined lettering is the reliable display/export version. The live-text file remains useful for future wording edits but may render differently if a matching font is unavailable or a different cut is installed.
