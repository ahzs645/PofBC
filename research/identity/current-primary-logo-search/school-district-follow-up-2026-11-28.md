# Current school district logo source audit — 2026-11-28

Source-link-only research against PofBC main `ce50bc6c209c26c2e29e390b3446c5526ae4d4b6` and the public gallery. Native artwork was checked using PDF objects in the actual logo region, not by treating a vector PDF page, OCR layer or adjacent text as a vector logo. No third-party logo files are included or cleared for reposting.

## SD43 · Coquitlam: native monochrome district mark

- Gallery: [current district identity](https://projects.ahmadjalil.com/PofBC/?view=gallery&logos=collected-school-district-43&mark=school-district-43-logo-current).
- Source: [district Directions 2030 plan, PDF page 1](https://media.sd43.bc.ca/media/Default/medialib/directions2030_final.c93a8c18494.pdf#page=1), linked from the [district's strategy page](https://www.sd43.bc.ca/vision-goals-and-objectives). PDF SHA-256: `1909b99f22610d9ff5e0cdcbeaf23d4a90bcd359a0e47e0cdc57e27eb8a1764b`.
- The upper-left monochrome package shows the parent/child and open book, the district lettering and boxed 43, with a separate Learning for a Lifetime strip. The logo region (approximately x 23–84, y 74–137 PDF points measured from the top left) contains 36 filled drawing records, sequence 658–693. There is no live text in that crop. The two full-page images are background; neither is a logo image object in this region. A 4× render visually confirmed the figures, lettering, numbers and strip. Directions 2030 itself is plan lettering, not part of the district mark.
- The [2026/27 Board work plan, p. 1](https://media.sd43.bc.ca/media/Default/medialib/board-of-education-work-plan-2026-2027.e2aa0518767.pdf#page=1) shows the current teal/black version without the tagline as a 146×121 bitmap. The native result is a genuine one-colour treatment of the same identity, not an exact colour master or a reason to replace the existing website specimen. Keep the full-colour source-vector gap open.
