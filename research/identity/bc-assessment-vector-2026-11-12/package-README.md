# BC Assessment vector logo

The official BC Assessment media kit provides the original EPS:
https://info.bcassessment.ca/about/contact/Pages/Media-Kit.aspx

Direct EPS:
https://info.bcassessment.ca/about/contact/StockImages/BCA-full-colour.eps

Retrieved 12 November 2026. The EPS on the supplied PofBC gallery is byte-for-byte identical to this official source.

## Files

- **bc-assessment.svg** - full logo, transparent, cropped to the artwork, with editable symbol and wordmark groups. Best for websites and vector editors. The lettering is already outlined and needs no font installation.
- **bc-assessment-symbol.svg** - the original five-part symbol extracted from the same vector source.
- **bc-assessment.pdf** - cropped vector PDF retaining source CMYK colours. The original white page background has been removed.
- **bc-assessment-original.eps** - unchanged official EPS, with its original full-size artboard.
- **bc-assessment.png** - transparent 1800-pixel-wide preview rendered from the SVG; this file is raster.
- **source-and-validation.json** - source URLs, checksums, conversion details and structural checks.

## Preservation and validation

The full logo consists of five symbol paths and twelve outlined letters. All original path geometry, symbol placement and wordmark spacing are retained. The SVG and PDF contain no embedded raster images or live text. These are conversions from the existing vector artwork, with no tracing or font substitution.

Only the outer page background and unused artboard margins were removed. The symbol is intentionally aligned above the right side of the wordmark, as in the original source.

The SVG uses RGB colours converted from the CMYK source. These RGB values are not claimed as official brand specifications. The original EPS and converted PDF preserve the source CMYK colours. The SVG and PDF are prepared derivatives; the EPS is the official download.

For the PofBC gallery, use bc-assessment.svg as the scalable display asset and retain the original EPS as the source download. This package does not imply a new licence or ownership of the logo.
