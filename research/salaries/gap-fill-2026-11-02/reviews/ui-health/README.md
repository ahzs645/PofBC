# Responsive salary interface review

The first review exercised the existing seven-collection local preview at widths 320, 375, 883 and 1280 pixels. This was headless Chromium with real viewport media queries, not a physical-phone or Safari test. The preview contained 1,350,754 payment records, 270 employers and 51 reporting labels. No salary data, source files or generated app assets were changed by the review.

At every width, Browse and Layout share a line without document overflow. Browse precedes the desktop sector controls; Positions hides sector controls in both the desktop toolbar and mobile sheet. The position note is the single line “Grouped titles · latest period averages.” Employer cards retain their reporting-year strips.

At both mobile widths, the filter icon opens the named modal dialog, focuses its heading, traps Tab and Shift+Tab, locks background scrolling, and closes with Escape, Close or Done while restoring focus. Search and sector changes persist; Clear filters resets them. A backdrop click closes the sheet. Changing to desktop width closes it and returns focus to the desktop search field. Period controls and sector chips remain scrollable inside the sheet. No page or console errors occurred.

All ten specifically reviewed damaged/clipped-name observations remain visible as noninteractive “Name unavailable” rows: two SD58, seven Vancouver Coastal Health and one Delta. Their exact known payments, source links and source caveats are present; zero expense remains $0 and unknown expenses remain a dash. The data table can scroll horizontally inside its region on mobile without overflowing the document.

The first review found one interpretation problem. Lalonde appears once in the municipal People browse, with the shared-name and likely-alias qualifications. Opening that card preserves the official 2023 payment and compiled 2023/24 observation, but the old detail page described the latter as the latest disclosure period without explaining that its label is an unverified compiled edition. Root authorized a narrow correction in `PersonPage.jsx`, `coverage.js` and `coverage.test.js`. It adds a possible-overlap warning, qualifies compiled and unverified labels beside records, and calls the summary “Latest label” when appropriate. Official-only histories retain their ordinary period wording. Both amounts and observations remain unchanged. The 59 salary Node tests and the JSX transform passed. Browser verification of the corrected page awaits root's next preview build.

Evidence is additive: [receipt.json](receipt.json) pins the first 22 screenshots and assets; [additional-checks.json](additional-checks.json) pins ten more screenshots, modal resize/backdrop checks, all ten source links, and the six original Lalonde source observations. These first receipts remain unchanged when the final nine-collection preview is checked. `check-preview.py` and `check-additional.py` reproduce these actions against the running preview, and accept `SALARY_UI_REVIEW_OUT=research/salaries/gap-fill-2026-11-02/reviews/ui-health/final-nine` for a later build so the first review is preserved. `SALARY_UI_SCOPE` records the reviewed build scope.
