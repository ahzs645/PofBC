Use ordinary public-record access for existing schedules or spreadsheets first.
Clarification tasks seek a source column definition, original numeric component or
existing electronic table. A formal FOI route is a fallback only after verifying
the municipality's process and routine access outcome. **No request or message was
sent.** No compiled employee or council group was deleted or relabelled.

This pass does not claim complete municipal history or exhaustive archive
discovery. Upload-path years, index labels, located documents and accepted named
payment disclosures remain distinct. The province-wide audit remains the roster
reference; this directory covers only the ten assigned municipalities.
