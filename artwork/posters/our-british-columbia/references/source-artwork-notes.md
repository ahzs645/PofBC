# Reusable artwork and reconstructed footer logos

## Files
- `bc-pavilion-expo86-reconstructed.svg`: 500 × 760, flag badge with blue double border and lettering. Reuses all twelve original vector path geometries of `PofBC/src/assets/flagMark.js`; recoloured to poster palette and adds white support silhouette. Main title group is `bc-title-insert` and now contains the root custom title reconstruction, fitted to x32, y370, width436, height184.
- `industrial-showmanship-reconstructed.svg`: 800 × 500. Gear, concentric rings, wings/feathers, camera reels/lens/body, globe and tripod individually constructed.
- `bob-rogers-company-reconstructed.svg`: 500 × 365. Stepped heavy slab text and a fourteen-aperture filmstrip.

All three files use paths and geometric shapes with no embedded raster and no live text. Production marks use blue #153c85; the Pavilion uses blue #163d8a, red #d9202d and yellow #f6b118. White fills are intentional print-paper knockouts, while outside each mark is transparent.

The 1986 Pavilion mark is not the Davidson poster's EXPO/three-ring symbol. That existing Expo symbol was inspected but excluded because it is a different mark. PofBC's later crest wordmark was also inspected and excluded because its flared sans lettering does not match the poster's serif lettering.

Small captions use outlined replacement type (Nimbus Roman; Stardos Stencil Bold; Alfa Slab One) and are not claimed to identify the original face. Historic linework is a constructive reconstruction for the tiny footer reproduction, not an original master.

The source listing unexpectedly provides unobstructed closeups of both marks, allowing the magnets in the user photo to be excluded without guessing the obscured wing/camera details. URLs and pinned repository provenance are in `footer-provenance.json`.
