FOREST AD SANS - RECONSTRUCTION WORKING FONT (v1.1)

Derived from Jost Italic (Google Fonts distribution, downloaded 20 November 2026), Copyright 2020 The Jost Project Authors. SIL Open Font License 1.1 (see OFL.txt).

Changes: instantiated variable weight at 600; retained the existing default single-storey italic a; disabled ss01 (the double-storey a alternative in this italic font); changed family/style names to Forest Ad Sans SemiBold Italic; set static font weight/style metadata. No glyph outlines were traced or redesigned.

The current italic font has the single-storey a by DEFAULT. The ss01 feature is the double-storey variant. This differs from descriptions of the upright Jost family.

This is a modern substitute selected for a Futura-family oblique appearance. It is not the authenticated font used in the 1971 advertisement. No exact historical font identification is claimed.
