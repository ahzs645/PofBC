# Analysis records

These scripts preserve the original workspace analysis and packaging workflow. Their relative paths refer to `work/revision3`, `work/revision2`, and the workspace output directory; they are not portable entry points in this archive. Use `../analyze_white_edges.py` from the package root to reproduce the merged final measurements and review boards. Use the independent `../reserves_v3.py` and `../rebuild_poster.py` to rebuild artwork.

Component comparison boards isolate the component being revised while retaining V2 geometry elsewhere. They supplement the final merged report and must not be mistaken for the full V3 output.
